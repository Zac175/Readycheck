# Readycheck

The complete character toolkit for WoW Classic: reminders, consumables, gear
and trinket swaps, world buffs, raid setups, time-to-kill and more.
Runs on Classic Era, TBC Anniversary and WoW Forever.

Type **/rc** in game to open it.

## Install

The easy way is an addon app that keeps it up to date for you:
**CurseForge**, **WowUp** or **Wago**.

By hand: download the zip from the newest [release](../../releases), and put
every `Readycheck*` folder inside it into
`World of Warcraft\_classic_era_\Interface\AddOns` (or the `_anniversary_`
folder for TBC). Restart the game.

## Updates

Addon apps update Readycheck for you. In game, Readycheck tells you once
per session when someone in your guild or group has a newer version.
